# Prototipo MVP - FlotaTrans S.A.

Prototipo interactivo (escala de grises, datos simulados) del sistema de gestión predictiva de flotas, organizado por sprint (1 a 5).

## Ver localmente
Abra `index.html` en un navegador moderno.

## Publicar en Netlify
1. En Netlify: **Add new site > Import an existing project** (o **Deploy manually** y arrastre la carpeta).
2. Si conecta el repositorio, no hace falta build: `netlify.toml` ya indica publicar la raíz.
